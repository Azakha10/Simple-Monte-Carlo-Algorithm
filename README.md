# Simple-Monte-Carlo-Algorithm

This algorithm is a simple application of the Monte Carlo technic, to simulate a photon's life, with fixed energy.
You can change the seed at the bottom of the code.

This code provides log for each interactions, and the total distance the particle traversed.
